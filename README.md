# YMM Project Manager

YukkuriMovieMaker 用の補助ツールです。

本ツールは以下の機能を提供します。

* 素材再リンク（自動探索）
* サムネイル生成
* 世代管理（.ymmp のローカルスナップショット保存・復元）
* `ymmpx` 同梱作成
* `ymmpx` 展開

---

# インストール方法

1. GitHub の Release ページから `YMMProjectManager.ymme` ファイルをダウンロードします
2. ダウンロードした `YMMProjectManager.ymme` を起動します
3. YukkuriMovieMaker の「ツール」タブからプロジェクトマネージャーを実行します

---

## 開発用ビルドと配備

YMM4の参照DLLを含むフォルダーを `YMM4_PATH` に指定します。CIと同じ参照を取得する場合は、PowerShell 7で `./scripts/fetch-ymm4-libs.ps1` を実行すると、新規の `libs/YMM4` に検証済みの参照DLLと来歴が保存されます。通常のビルドやテストからYMM4への配備は行われません。

```powershell
$env:YMM4_PATH = 'C:\path\to\reference-dlls'
dotnet build .\YMMProjectManager.sln -c Debug
```

開発先へ配備する場合は、対象のYMM4を終了し、配備先を指定して専用ターゲットを実行します。この操作で配備先のプラグインDLLが更新されます。

```powershell
dotnet msbuild .\YMMProjectManager\YMMProjectManager.csproj -restore -t:DeployToYMM4 -p:Configuration=Debug "-p:YMM4DeployPath=C:\path\to\YMM4"
```

タグの配布ワークフローでは、Releaseビルドと隔離テストの成功後に `YMMProjectManager.ymme` を組み立てます。付属する `YMMProjectManager.build.json` に、試験対象コミット・参照DLLの版とSHA-256・パッケージのSHA-256が記録されます。

# 主な機能

## 素材再リンク

.ymmp ファイル内の素材（画像 / 動画 / 音声）のリンク切れを検出し、自動探索で修復します。

## プロジェクト一覧表示

.ymmp ファイルを登録してプロジェクトの一覧を表示します。登録したプロジェクトはサムネイル付きで管理できます。

一覧の右クリックメニューから次の操作ができます。

* 世代を保存
* 世代一覧
* 世代診断

世代管理は Git を使わず、`%AppData%\YMMProjectManager\Generations\` にローカル保存します。

保存対象は `.ymmp` 本体のみです。画像、動画、音声、フォント、素材フォルダは保存しません。

復元時は既定で元ファイルへ戻し、復元前バックアップを作成します。

## 世代診断

`世代診断` では次の情報を確認できます。

* ProjectId
* ProjectPath
* GenerationCount
* StorageSize
* LatestGeneration
* ManifestStatus
* DeletedGenerationCount

破損時の動作:

* manifest 破損時は読み込みエラーを表示し、世代の新規保存・削除を中止します
* metadata 破損時は壊れた世代だけを無効化し、残りは表示します
* SHA256 不一致時は復元を禁止します

## YMMPXで素材を受け渡す

### 同梱する

1. 対象のPFを一覧で選び、`選択したプロジェクトを同梱` を押します。YMM4で開いているPFは `現在のプロジェクトを同梱` から選べます。
2. 素材の読取りを許可するフォルダーを選びます。素材名、サイズ、SHA-256を確認し、各素材の再配布許諾を選択します。
3. 新しい出力フォルダーを指定します。選択した素材を含む `.ymmpx` と照合記録 `ymmpm-transfer.json` を保存します。受け渡す際は2つを同じフォルダーに置いてください。

再配布の許可を確認済みの素材と、自作・権利保有を申告した素材だけを同梱します。確認できない素材や連番PNGは除外されます。元PFと元素材は保持されます。

### 展開する

1. `ymmpx展開` を押し、受け取った `.ymmpx` を選びます。
2. 新しいフォルダーを作成する場所を選びます。照合記録付きの場合はパッケージと各素材のSHA-256を検証します。
3. 不足が表示された場合は配布元に確認します。一覧に登録する場合は、展開後の確認で新しいプロジェクトとして登録します。

新規作成には `YmmpxLibPlugin` が必要です。YmmpxLib が標準の `.ymmpx` を作成し、プロジェクトマネージャーが元の素材名・許諾・SHA-256を照合記録（v2）に保存します。作成中は出力先に、許可した素材の一時コピーとパッケージを置く空き容量が必要です。プロジェクトマネージャーで展開すると、v1・v2の照合記録から同名素材も別々に元名へ復元します。展開に追加ライブラリは不要です。従来形式のパッケージは対応する展開経路で開けます。従来形式の素材に照合記録がない場合、完全SHA-256で照合済みとは表示しません。

未導入または非対応のときは、新規作成から対応する公式 `YmmpxLibPlugin v1.1.0` の案内を開けます。ダウンロードを承認すると、保存前に配布ファイルのサイズとSHA-256を検証します。保存した `.ymme` は YMM4 のプラグイン導入手順に従って開き、導入・更新後に YMM4 を再起動してください。旧 `YmmpxLib` フォルダーは表示して保全します。

## 再リンクの使い方

1. プロジェクトを開きます
2. `開いているPFを再リンク`をクリックして、素材再リンクウインドウを開きます
3. `ファイル検索`をクリックして、素材の再リンク処理を開始します
4. 結果を確認して、必要に応じて候補を選択して修正します
5. `更新内容を保存`をクリックして、プロジェクトを更新します
6. 自動でタイムライン上の素材リンクが更新され、再リンクされます

---

## サムネイル生成

プロジェクトのプレビューからサムネイルを生成します。

* 64点サンプリング
* 非同期処理
* UI操作に影響を与えない設計

注意：

* YMM の表示状態に依存します
* プレビューが更新されない場合は取得できないことがあります

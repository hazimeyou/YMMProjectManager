# YMM Project Manager

YukkuriMovieMaker 用の補助ツールです。

プロジェクト一覧から素材の厳格再リンク、素材プール、Git履歴、YMMPXによる受け渡しを利用できます。

v0.5.0の正式対応環境は Windows 11 x64、.NET 10、YMM4 Lite 4.57.0.1、ローカルストレージです。YMMPXの作成には対応する公式YmmpxLib 1.1系を使用します。Windows 10、他のYMM4版、NASやネットワーク上のストレージは正式保証の対象外です。実環境の受入状況は [R33の記録](docs/development/v0.5.0-r33-nonvm-development.md) を参照してください。

# インストール方法

1. GitHub の Release ページから `YMMProjectManager.ymme` ファイルをダウンロードします
2. ダウンロードした `YMMProjectManager.ymme` を起動します
3. YukkuriMovieMaker の「ツール」タブからプロジェクトマネージャーを実行します

---

## 開発用ビルドと配備

YMM4の参照DLLを含むフォルダーを `YMM4_PATH` に指定します。CIと同じ参照を取得する場合は、PowerShell 7で `./scripts/fetch-ymm4-libs.ps1` を実行すると、新規の `libs/YMM4` に検証済みの参照DLLと来歴が保存されます。通常のビルドやテストからYMM4への配備は行われません。

```powershell
$env:YMM4_PATH = 'C:\path\to\reference-dlls'
dotnet build .\YMMProjectManager.sln -c Debug
```

開発先へ配備する場合は、対象のYMM4を終了し、配備先を指定して専用ターゲットを実行します。この操作で配備先のプラグインDLLが更新されます。

```powershell
dotnet msbuild .\YMMProjectManager\YMMProjectManager.csproj -restore -t:DeployToYMM4 -p:Configuration=Debug "-p:YMM4DeployPath=C:\path\to\YMM4"
```

タグの配布ワークフローでは、Releaseビルドと隔離テストの成功後に `YMMProjectManager.ymme` を組み立てます。付属する `YMMProjectManager.build.json` に、試験対象コミット・参照DLLの版とSHA-256・パッケージのSHA-256が記録されます。

# 主な機能

## プロジェクト一覧・再リンク

一覧に `.ymmp` を登録し、開く、移動・改名の関連付け、旧ID・メタデータ履歴の確認を行えます。保存競合や中断では、一覧の回復画面で内容を確認し、必要に応じて原本や候補を別名で退避できます。

`選択プロジェクトを再リンク` で、承認した検索先や素材プールから、元の素材名と完全SHA-256が一致する候補を探します。確認した候補で別名PFを保存し、元のPFと素材を保持します。開いているタイムラインからは候補を確認できます。タイムラインへの直接反映は停止中です。

## Gitと旧世代の救済

履歴管理にはGitを使います。選択したPFのリポジトリで初期化、状態・履歴、ブランチ、個別ステージ、確認付きコミットを利用できます。リモート操作はClone、Fetch、確認付きfast-forward Pull、non-force Pushを提供します。認証の正式対応先はGitHubです。SSH認証は正式保証の対象外です。

素材本体、素材入りYMMPX、復旧データ、資格情報はGitで公開できません。PMは既知の素材と非公開データをStage・Commit・Push前に確認し、Pushでは送信対象の履歴も検査します。未知の変換データや外部Gitクライアントによる操作には検出の限界があります。

旧世代は `旧世代からPFを取り出す` から、対象世代の `metadata.json` を選択して別名の `.ymmp` へ出力できます。サイズとSHA-256が必要です。目録・元PF・旧世代・復元前バックアップは保持されます。別フォルダーに出力すると相対素材参照の解決先が変わる場合があります。 [旧世代の救済手順](docs/architecture/adr/legacy-generation-export-r32.md)

## YMMPXで素材を受け渡す

### 同梱する

1. 一覧のPFまたはYMM4で開いている保存済みPFを選び、同梱を開始します。
2. 許可する素材の読取りルートを指定します。対象・除外・欠落を確認し、UI情報を含めるかを選びます。欠落を含めて続行する場合は確認が必要です。
3. 出力先を指定します。標準の `.ymmpx` を新規保存し、元PFと元素材を保持します。

`YMMPX 除外設定を取り込む` からPackagerの除外設定を確認し、PMの共通設定または選択したPFの設定に取り込めます。PMとPackagerは設定をそれぞれ保存します。共通設定にPF別ルールを合成し、解析できない設定がある場合は作成を停止します。

### 展開する

`ymmpx展開` から標準ファイルを選び、新規フォルダーに展開します。一覧への登録は展開後に確認します。追加ライブラリなしで展開でき、既存のPM v1と開発時v2の関連記録も読み取れます。旧照合記録は手元のパッケージと素材の整合を検証するために使います。

未導入または非対応のときは、新規作成から対応する公式 `YmmpxLibPlugin v1.1.0` の案内を開けます。ダウンロードを承認すると、保存前に配布ファイルのサイズとSHA-256を検証します。保存した `.ymme` は YMM4 のプラグイン導入手順に従って開き、導入・更新後に YMM4 を再起動してください。旧 `YmmpxLib` フォルダーは表示して保全します。作成には、公式配布物と同じDLLが必要です。開発用に `YMMPX_LIB_PATH` を指定した場合は指定されたファイルを検証し、確認できない場合は通常の導入先へ切り替えず作成を停止します。

## サムネイル・比較・データ管理

一覧は既存のサムネイルを表示します。`サムネイル` から選択PFの保存済み画像を最大64点閲覧できます。画像と対象PFの照合範囲は画面に表示されます。

`プロジェクト比較…` で元PFと現PFを選び、共通時刻、固定オフセット、切り替える区間の開始時刻を設定できます。比較設定は別名保存・再読込できます。実YMM4での独立Sceneの受入まで、新規サムネイル描画と左右の描画は停止中です。

PM設定から確認済みキャッシュ、旧形式・未照合キャッシュ、中断物、診断ログの使用容量を確認できます。削除を選んだ場合は対象の所有証拠を再照合します。復旧記録、旧形式キャッシュ、所有を確認できないファイルは保全します。

# 既知の制約

- 電源断、OSクラッシュ、ストレージ・ファイルシステム故障に対する完全な耐久性は保証しない。Flush(true) と同一ディレクトリの置換は実測対象外のすべての環境での保証ではない。
- 同一プロセス内の保存を直列化するが、別プロセスによる編集を検出しない。外部競合では後の置換が上書きし得る。
- ファイルシステムが File.Replace をサポートしない場合、既存ファイルを削除して移動せずエラーを返す。各種ネットワーク共有での挙動は未検証。
- 実 UI のメッセージ表示、読み込み失敗からの回復、ACL拒否、実ディスク容量不足は未検証。保存前にメモリ上で行った変更は自動ロールバックされない。
- 同一プロセスの全一覧保存を1つの semaphore で直列化する。複数プロセスにわたる順序や編集の完全な競合制御は対象外。
- 一時ファイル削除の失敗は元の例外を優先するため、temp が残り得る。既存 .bak は追加・変更しない。
- 構文的に有効な JSON の意味的な妥当性検証は追加していない。未知プロパティは既存 DTO の挙動に従い、round trip で保持されない場合がある。

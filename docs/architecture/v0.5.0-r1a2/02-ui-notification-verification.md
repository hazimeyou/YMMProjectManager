# UI 通知

Windows の独立 WPF Dispatcher 上で本 ViewModel、合成ファイル、一時保存先と注入した IOException を使用。テストは同一 WPF スレッドの `#32770` ダイアログを検出し閉じる。追加と削除失敗、および破損・空・共有ロックの読込失敗でダイアログを観測。ダイアログの文面・実際の XAML 表示や YMM ホスト内での表示は自動検証していない。キャンセルを注入した追加ではエラーダイアログを検出せず、元ファイルを保持した。成功と再試行のテストが完了したが、全画面の通知抑制を証明しない。

コードでは汎用エラーを `MessageBox.Show`、キャンセルは `OperationCanceledException` 専用 catch でログのみ。未保存時に一覧画面の状態表示と再試行ボタンを提供。ViewModel の bool / command 状態は独立テストで検証したが、見た目・ボタン操作の実 UI 受入は未実施。

# 失敗後の回復

R1-A 基準で合成プロジェクトを追加し置換前 IOException を注入。警告ダイアログ、画面モデルに1件残存、ディスク元の hash 不変を観測。失敗原因を解除して同じ AddProjectsAsync を再実行すると重複と判定され、保存要求回数は増えずディスクは空一覧のままだった。これを確認後、既存画面に未保存表示と保存のみ再試行コマンドを追加。

修正後、追加を重複せず保持したまま再試行し、別 repository から1件を再読込。削除失敗・登録失敗・キャンセルでも保留状態を維持して保存だけ再試行し、内容を再読込した。登録は private method を直接呼んだ独立試験であり、実 YmmpxLib の展開を実行していない。

保存失敗時の合成元 JSON の SHA-256（修正後試験）は前後とも `76D257EB95081B0F58EBEAB55B32CD9625666878EAD867B71B959EC8F44AD12D`。再試行成功後は未保存表示を解除する。保存前に行われた外部起動や展開は戻せない。アプリ終了時の未保存警告はない。

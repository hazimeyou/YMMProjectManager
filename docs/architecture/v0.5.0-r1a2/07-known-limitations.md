# 既知の制約

- 実ホスト・実画面の表示、ボタン操作、YmmpxLib 展開後の一連の動作、ACL 拒否は未検証。独立 WPF は MessageBox の存在を検出したが文面を自動検証していない。
- 保存失敗後の変更はメモリに残り、保存成功まではディスクと異なる。終了時に保留データを保護・警告する仕組みは追加していない。未保存状態はプロセス内のみ。
- 読込失敗時は空一覧を上書きしないが、画面の Loaded は一度しか初期化しない。原因解消後の同一画面での読込再試行は未提供。画面の再作成等の実ホスト回復手順は未確認。
- 別プロセスの更新検出、完全な電源断耐性、未知 JSON フィールド保持は R1-A の制約のまま。

# 制約

- 世代保存・削除は複数プロセス間で排他せず、検証と置換の間に外部変更された場合、完全保護を保証しない。固定名 manifest `.tmp` を共有する既存構造の並行保存は未検証。
- 旧仕様の公開モデルと実際の現行 serializer を基に必須項目を判定した。過去の実ユーザー manifest の網羅的な互換性は未確認。必要項目を欠く旧データは安全側で書込みを拒否し、自動変換しない。
- 未知の JSON フィールドは既存の型へのデシリアライズで保持されない。schema 1 内の未知拡張がある場合の保存互換性は未確認。
- ストレージ、電源断、書込み途中の I/O 故障、ACL 拒否、実ホスト UI は未検証。固定 temp の cleanup と既存の復元の失敗分岐は変更していない。
- R1-A2 の実ホスト受入、ACL と終了時未保存表示などの制約は継続して未解決。

# VM 構築 — BLOCKED

新規 VM、仮想ディスク、仮想スイッチ、guest OS、Windows 機能は作成・変更していない。VM 管理機能と操作権限、十分なディスク容量、guest OS 媒体と使用権、隔離・復元方法が確定していない。

再開前にユーザーが、十分な余裕を持つ専用保存先を確保し、管理者が読み取り専用で利用可能な仮想化基盤と既存 VM を確認する。新規 VM 名・保存先・独立した仮想ディスク・ネットワーク未接続・共有無効・checkpoint と guest OS のライセンス／インストール元を具体化する。Hyper-V の有効化、Windows 機能変更、再起動、仮想スイッチ変更は、その具体的な影響を提示してユーザーの明示承認を得た後に限る。既存 VM の再利用は別途明示承認が必要。

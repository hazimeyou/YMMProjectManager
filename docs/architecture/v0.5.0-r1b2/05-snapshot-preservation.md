# Snapshot 操作と回復

作成は Snapshot と metadata を先に作成して Manifest 保存し、失敗時に新規ディレクトリを削除する。部分書込み、flush、置換、外部変更失敗の合成試験では旧 snapshot hash 不変、失敗作成のディレクトリは残らなかった。後始末自体の失敗・プロセス強制終了・電源断では孤立した未参照ディレクトリが残り得る。

削除は旧ディレクトリを deleted へ移してから保存し、失敗時に元の位置へ戻す。部分書込みと外部変更の各試験で元位置への復帰と hash 不変を確認。復旧移動が失敗する場合の状態は未注入で、deleted 領域に残り得る。旧世代 ID を指定する RestoreAsNewFile は合成 fixture で成功した。

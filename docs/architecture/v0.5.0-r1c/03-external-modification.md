# 外部変更と並行

scan 時に取得した元バイト列の SHA-256 を保存直前のファイルと比較。一時ファイルと backup 作成後にも再確認し、異なれば保存を拒否して再読み込みを案内。取得した backup の hash も元の hash と一致しなければ中止する。同一プロセスの同一正規化パスは semaphore で直列化し、同じ初期状態から2保存すると1件は成功し他方は衝突となる。

SHA-256 比較と File.Replace の間には別プロセスによる変更窓が残る。別名リンク、別プロセス排他、電源断耐性は保証しない。成功後に同じ scan context を再利用すると旧 hash との不一致になるため再読み込みが必要。

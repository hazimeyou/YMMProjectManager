# 対象限定 JSON 更新

JsonNode の再シリアライズは未知フィールドの値は保持できても、空白・数値・エスケープの表現が変化し得る。独自の JSON パーサーを作る代わりに Utf8JsonReader で値のバイト範囲を抽出し、scan の行番号と元値を照合し選択値トークンのみ置換。項目順、空白、数値表現、対象外文字列・未知フィールドは元バイトを保持する。置換値は標準 serializer で適切にエスケープ、保存前に JSON parse。重複プロパティ、重複行、不一致、Items の配列要素直下以外の FilePath は安全に識別できず拒否する。後者は既存 scan が探索した未知 plugin 下のパスの誤更新を防ぐためで、そこが正当な素材を含むかは未確認。

UTF-8（BOM有無）を扱い、UTF-16 等は厳格 UTF-8 デコードで読込失敗。コメントや標準外 JSON は従来 JsonNode と同様に対象外。2つの同一元値を別候補に変更し、Items 外の同値と数値表現・改行・未知データがバイト単位で保持されたことを確認した。

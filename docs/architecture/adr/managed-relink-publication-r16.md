# ADR: 管理再リンク出力の公開と回復

状態 **採用**。既存の保存済みプロジェクトに対する SaveAs を対象とする。

R15 の出力照合は SHA-256 を使っていた。同じ内容の別ファイルを、最初のメタデータ更新前に出力の場所へ置いた場合、確認済みの出力を識別できなかった。

R16 の回復記録 v4 は元ファイルの物理 ID と SHA-256 を保持する。新規作業ファイルを排他的に作って同期した後、同じハンドルから得た作業ファイルの物理 ID と SHA-256 を公開記録に保存する。次に既存のファイルを置換せず、そのハンドルに結び付いた出力だけを公開する。作業ファイルと公開先は元プロジェクトと同じディレクトリを使う。YMMPX で検証済みの Windows のファイル操作を共有する。

公開前に止まった操作は、利用者が明示的に回復を選んだ場合にだけ続行する。元、候補、公開記録、作業ファイルを照合する。出力が既にあれば、検証済みの物理ファイルと一致する場合に限ってメタデータ版の確認を続ける。既存の出力を移動・削除せず、保存済み版は同じ操作 ID で照合する。公開記録が無い段階の中断や破損した記録は自動で再実行しない。候補や系列が後から変わった場合、出力や履歴を保持したまま止まることがある。

v1〜v3 の読み取りを維持する。旧記録には v4 の公開証拠がないため、旧記録の復旧で同じ物理出力を保証する範囲は広がらない。旧版での確認前に記録と同階層の作業ファイルを複製する。ホストのタイムライン、電源断、非協調プロセスや不正な手動操作に対する耐性は受入未実施。

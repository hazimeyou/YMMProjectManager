# 復旧・再開手順（計画、未実演）

1. 実行前に専用 VM の位置・所有者、仮想ディスクと共有設定、基準状態のスナップショットまたはバックアップの復元手順を管理者が確認する。ホストデータを共有させずに復旧可能か確認する。
2. ゲスト内に作った synthetic fixture とログだけを使用し、作成した状態と停止方法を記録する。検証成果の持ち出しは内容と目的地を確認し、clipboard や共有フォルダを常時開放しない。
3. 自分が開始した YMM4 とその子プロセスを通常終了し、状態とログを確認する。名前だけで無関係なプロセスを kill しない。失敗時は VM を保持し調査する。
4. 検証後の VM 状態を保存したうえで、ユーザーが確認した復元ポイントへの復帰方法を実演・検証する。実際の VM がないため、この工程は未実施。

既存 worktree、実ユーザーファイル、profile、cache、plugin、registry は削除・上書きしない。共有遮断を含む VM 管理変更は具体的な環境と影響範囲の確認後に実施する。

## タイムライン契約調査

隔離済み参照のホスト本体 DLL は `4.57.0.1`。既存の一括再リンクは `TimelineToolInfo` から項目を読むことはできるが、変更の要求を受けた時点で停止する。単一項目の旧サービスには、直接 setter の後に任意の Undo 記録を呼ぶ公開メソッドが残っていた。呼び出す UI は見つからなかったが、setter 成功後に Undo 記録が失敗すると部分反映の可能性があるため、入口を停止した。

開発元は 4.57.0.0 で型付きコマンド API を公開した。調べた資料からは、素材差し替えの対象型・UI スレッド・Undo/Redo・複数項目の巻き戻し・保存を一体で扱う契約は確認できなかった。隔離ホストで受入可能になった時点で該当コマンドと対応バージョンを確認し、未保存状態、Undo/Redo、保存と再読込、途中失敗を試験する。 [YMM4 公式リリース記録](https://manjubox.net/ymm4/release/4.57.0.0/) [開発元のサンプル](https://github.com/manju-summoner/YukkuriMovieMaker4PluginSamples)

# v0.5.0 TL-2B 引継ぎ

TL-2B はホスト非依存アダプターと隔離実機受入の準備。TL-2A 基点は `a1f5e54ca542f94800190e38177cd8f78f0eccf0`。再開先は `codex/ymmpm-v050-tl2b-host-adapter` の検証済み HEAD。

| 状態 | 対象 |
| --- | --- |
| IMPLEMENTED | TL-2A の契約を使った A→B→A、操作相関、借用画素の独立コピー、編集状態の観測契約、取消・期限、例外・解放、実験用 Pbgra32 コピー。 |
| SYNTHETICALLY_VERIFIED | 合成 source の順序、独立性、競合・再入、失効、誤応答、観測不能、終了処理、回帰。 |
| REAL_HOST_VERIFIED | 該当なし。 |
| UNVERIFIED | Scene owner・寿命の実機取得、全状態観測と排他、実フレーム・色・画素形式・GPU/スレッド契約。 |
| DISABLED | PM の製品経路からの Scene 描画。 |
| BLOCKED | 実機受入の環境と明示承認、実機の読み取り・排他契約。 |

次の作業は、許可済み隔離環境で同一プロジェクトの Scene owner・寿命・状態の読み取り専用観測を成立させ、逐次 A→B→A の受入を実行すること。実験変換の自動導入は、元画素の契約確定後に判断する。v0.5.0 のリリース判定は変更しない。

## 主なボトルネック

1. 一覧保存と WPF の中断試験。モーダル応答を待つ子プロセスで統合試験が止まった。所有子プロセスに期限を設け、終了と出力回収を検証して再実行した。
2. Git の更新境界。HEAD ロック下でも途中まで更新されるケース、ref だけが更新されるケースを隔離して調べた。Clone の公開は名前で追い直す方式を避け、所有するディレクトリを開いたまま公開した。
3. 回帰環境。共有 TEMP により出力が衝突した。長い隔離パスでは Git が `PathTooLong` を返した。試験ごとに短い一時領域を用意し、試験で見つかった世代 Manifest 読み取りと置換の干渉を別途修正した。

worktree 作成と cherry-pick の測定は INTEGRATION の生データ参照。deferred 区間には別の作業を含む。変更レビュー・待ちを含めた統合工数、worker 完了から統合までの実働、個別の待ち時間は NOT_MEASURED。次回も短い専用 TEMP を最初に確保し、子プロセス終了条件のある試験を先に実行する。

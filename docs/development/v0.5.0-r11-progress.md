## 作業分担と契約

実装可能 subagent と管理 worktree を確認し、以下を同時に進める。Controller 以外は共通 UI、モデル、Program.cs、csproj、他 worktree を変更しない。各作業は合成 fixture と隔離 YMM4 参照で build/test し、個別 commit と差分・制約を報告する。Controller が変更とテストを確認して取り込み、統合 regression と独立レビューを担当する。

| Workstream | 所有と変更範囲 | 受入・統合 |
| --- | --- | --- |
| A / controller | project list / asset / relink と共通 WPF | 保存済み・未保存・外部更新を区別し、ユーザーの変更を消さない。合成競合、失敗、UI テスト。 |
| B / git worker | `Infrastructure/GitRepository.cs` と Git tests。worktree `ymmpm-r11-git`、branch `codex/ymmpm-v050-r11-git` | ローカル合成 remote のみ。再現済みの安全な局所変更、unsafe Pull と UI は保証がなければ停止維持。commit と検証証拠を controller に報告。 |
| C / ymmpx worker | `Infrastructure/Packaging/` と Ymmpx tests。worktree `ymmpm-r11-ymmpx`、branch `codex/ymmpm-v050-r11-ymmpx` | 合成データと隔離参照のみ。安全性未証明なら抽出停止維持。commit と検証証拠を controller に報告。 |

本番 YMM4、共有 VM、実ユーザープロジェクト、実 remote は使用しない。共通の参照 DLL は読み取り、build 出力・TEMP は各 worker が隔離する。push / merge / 公開は禁止。

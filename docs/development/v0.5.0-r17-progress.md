# v0.5.0 R17 統合進捗

基準 `10432ad`、統合 `codex/ymmpm-v050-r17-continuous-completion`。R16 の基準 HEAD と試験済み HEAD の間に実行コード差分なし。既存 worktree を保持し、独立した3つの作業ツリーを作成した。

- **Git** `b01660d`、`1b9abb4`、`e26c7c2`。無視対象と取り込むパスの衝突を診断し、UTF-8 を明示。実ファイルの HEAD を固定しても index と作業ツリーが先に変わる隔離結果を記録。 [Pull の契約](../architecture/adr/git-pull-recovery-r17.md)
- **一覧** `530ec7c`、`f539ad9`、`1301bb3`、`99176ed`。照合した一覧を退避し、その名前が空いている場合だけ候補を公開。競合の全版を保持し、明示回復では物理 ID と SHA-256 を再確認。対応する固定 NTFS と権限だけを書き込み対象にする。WPF `b696894`、`2a298b9`、`5b30284`。 [保存と回復の契約](../architecture/adr/project-list-publication-r17.md)
- **Identity・管理付き再リンク** `29c403d`、`c4e7d1c`、`f7103ce`、`8b6f7e2`、`626a355`。初回・復旧の双方で、メタデータの枝の確認を終えるまで候補を非公開。旧版一時ファイルは保持したまま履歴の対象から外し、履歴移行に正確な作業ディレクトリを使う。
- **YMMPX・外部素材・世代** `ecb637e`、`33aa53b`、`723a785`、`8ec60e0`、`075b15d`、`8dd2584`、`6d0570d`。現行 YMMPX の作業境界、ディレクトリの所有、Unicode 応答を検証。所有不明の一時ファイルは保持。外部素材検査を UI スレッド外へ移し、世代削除を確定できない場合に保全対象の場所を返す。

実 DLL で、予約済みの一時ファイルと最終アーカイブの物理 ID が異なることを最初の試行で確認した。ID 一致を必須にした試作は取り下げ、作業ディレクトリの固定、ZIP 検証、選択したプロジェクト名の照合、確認したハンドルからの公開に変更した。ライブラリ呼び出し中に同じ権限で作業ディレクトリの**内容**を置換する相手に対して、同名アーカイブの元データまで証明する契約は残っている。

各分類は公開 API の形と YMMPrint R2 の静的・合成証拠に基づく。**REAL_HOST_VERIFIED に分類できる項目は現時点で0件。** 調停器は合成証拠で検証しただけで、実機の getter やホスト登録を追加していない。

## 観測の条件

ホスト文脈は、確認できた全対象の観測を1つの同じ Dispatcher 文脈にまとめる。初期の観測値と各段階の観測を照合し、可能なら通知を購読して一過性の変化も検出する。値が元に戻ってもバージョントークンを再利用しない。前後の値だけが一致しても観測間の変更がなかったことは立証できない。

`SceneRenderObservation.EditorStateVersion` はその保証をできる文脈でのみ非空トークンを返す。観測不能、通知の欠落、寿命切れなら null または観測エラー。調停器は各描画前、比較前、返却前と、失敗・取消後に観測して結果の公開を止める。観測処理自体に編集作用がないことも検証する。状態を戻す操作は追加していない。ホストに変更を検出したら記録し、その実行範囲での受入を中止する。

SDK でカバーできない状態が残る場合は、観測の制約を明記して該当受入を保留し、製品接続を無効のままにする。

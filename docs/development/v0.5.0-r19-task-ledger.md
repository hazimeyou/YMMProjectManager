# v0.5.0 R19 タスク台帳

指示 ID `YMMPM-R19`。開始・終了マーカーとセクション0〜24を確認した。リポジトリ `hazimeyou/YMMProjectManager`、origin `https://github.com/hazimeyou/YMMProjectManager.git`。R18 の `2a0176f` はクリーンで、試験済み `dec3378` からの差分は文書7件。新しい統合 worktree と3つの worker worktree を用いた。

| ID | 要件 | 担当 | 状態 | 根拠と次の工程 |
|---|---|---|---|---|
| R19-A | 承認された fast-forward Pull | Git / Controller | VERIFIED（隔離） | 旧・新 OID と remote/ref を固定。dirty、分岐、競合、別 branch、リモート変動、書き込み中の競合を拒否・検出。現行 Git for Windows と固定ローカル NTFS でローカル bare remote を検証。次は管理された HTTPS と実ホストで受入。 |
| R19-B | 取消・不明な結果の保全 | Git / Recovery / Controller | VERIFIED / PARTIAL | 更新前の取消は checkout を維持し、起動後の取消は照合まで待つ。不明な場合は再起動後も証拠を保持。準備 timeout、Git 起動前と完了後にアプリ子プロセスを終了、非協調の ref 変更を検証。ネイティブ Git 更新途中の強制終了・電源断は未検証。 |
| R19-C | WPF 承認と診断 | WPF / Controller | VERIFIED（隔離） | 接続と更新を別々に承認。既定は取消。承認対象の変更を拒否し、失敗・回復記録を表示する。モーダル実操作は隔離 YMM4 で受入を行う。 |
| R19-D | R18 既存機能の回帰 | Controller | VERIFIED | `b17db4f` の Release/Debug の実 DLL 有無4構成で各62グループ・120個別成功、失敗0。実 DLL なしのみ明示スキップ1件。 |
| R19-E | release-review evidence | Controller / 独立レビュー | VERIFIED | WPF と backend の別試験、独立 bare remote 受入、外部フィルター検査と保全の指摘を反映。最終コード・試験・残件を記録。 |
| R19-F | 実環境と対象外 checkout | Controller | UNVERIFIED / DISABLED | 認証が必要な HTTPS Pull、特殊 Git 設定、linked worktree、対応 FS 以外では実行しない。別途認証契約と隔離環境が必要。 |

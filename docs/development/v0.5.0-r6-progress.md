# v0.5.0 R6: 途中経過と再開地点

状態: PARTIAL / release candidate 未達。基準は R5 `dec0d96e47cff28fb59775358f4843a2f8c77d22`。

## 完了した局所修正

- 既存世代 ID と衝突した場合、既存 manifest や snapshot を上書きしない。生成ディレクトリは Windows の単一の排他的作成操作で確保し、自分が作成した場合のみ後始末する。manifest だけでなく孤立ディレクトリの衝突も拒否する。
- 世代 ID のディレクトリ区切り、相対パス等を拒否し、manifest 読込時も同じ検証を適用する。削除は manifest に存在する ID のみを対象とする。世代ディレクトリ自体が reparse point の場合、復元と削除を拒否する。
- 別ファイルとしての復元は、既存ファイルを上書きしない移動で公開する。

独立レビューの指摘後、いずれも実装に対する合成 fixture で確認した。旧コードでは固定 ID の衝突を受け入れ、別ファイル復元で既存合成ファイルを上書きした。独立レビューでは不正 ID による領域外ディレクトリ移動も実 API で再現された。修正後の fixture は旧 snapshot の SHA-256、孤立ディレクトリ、領域外 sentinel、既存復元先の SHA-256、破損 manifest の SHA-256 を確認する。

## 未完了と安全上の制約

- Git remote UI は既存の安全停止を継続。公開 `GitRepository.PullAsync` は HEAD 確認後に別操作が branch を切り替えると別 branch に pull し得る。独立レビューで同じ Git コマンドの挙動を合成 repo で確認したが、製品 API の決定的競合 fixture と修正は未実施。公開 API 利用を安全と判断しない。
- Project identity、移動・コピーの区別、metadata 連携は未実装。途中の nullable ID 実験は取り除いた。旧形式互換、重複 ID と保存失敗の検証が必要。
- Git の設定・credential・hook、素材関連付け、hash-aware relink、YMMPX bridge の安全な展開、実ホスト受入と RC/VM package は未完了。R5 ledger の未完了事項を引き継ぐ。
- 世代保存の親ディレクトリの reparse point と検査後の置換競合、複数プロセスによる filesystem 変更、電源断耐性は完全に保証していない。今回の reparse 保護は世代ディレクトリ自体に限る。実際のホスト UI と長期互換性は未検証。
- 修正後差分の独立再レビューは完了していない。レビュアーの再実行は自動安全審査により中断された。

次の着手: 合成 bare repository と `BeforeRemoteExecution` を使って公開 Pull API の branch 競合を決定的に再現し、競合時も誤った branch を変更しない方式または明示的な安全停止を実装・回帰検証する。

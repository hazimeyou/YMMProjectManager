# v0.5.0 R24 独立レビュー

Worker Cは統合コード `d241b467ad96d8c67c25ebf51b4b4abf20886e23` を起点にR23基準との差分および最終コード c34255a を確認し、UI承認、リポジトリの照合、構成ファイルの保持、限定したGit起動、取消、表示の秘匿を確認した。レビューとは別に、隔離ReleaseでYMMPX・素材誤公開防止の7指定スイートを実行した。統合後の全回帰はControllerの実測を使う。

| 優先度 | 内容 | 処置 |
|---|---|---|
| 受入ゲート | 初回ログイン・再ログインの実ブラウザとWindowsストアの成功・失効は未受入 | 公式GCM 3.0.2 x64に限定して有効化。旧版の迂回を再現し、新版の合成OAuth・転送拒否・実OS子プロセス終了を確認 |
| P1 | 既存のアクセス確認で選択時と起動時のorigin・物理レポジトリが独立 | 承認した型付き対象を保持し、実行直前の同じGitで物理IDと保持した構成のURLを比較。独立レビューの範囲で有効な差分に新規P0/P1なし |
| P2 | ローカルのPDBとDLLのCodeViewに作業フォルダーの識別子が含まれた | 候補はPathMap付きReleaseの試験済みDLLを採り、PDBを除外。候補内の4ファイルを再照合 |
| P2 | 既存の複数アカウントから非対話で選べない場合がある | ブラウザの成功と対象リポジトリのアクセス可否を分け、後続操作を明示承認。専用のアカウント選択は残る |
| P3 | ブラウザ認証用に許可するGCM更新の管理 | 検証したMicrosoft署名済み公式バイナリと同じSHA-256に固定。将来版は同じ検証を行って明示追加 |

公開先の確定、実ブラウザ認証、資格情報ストアの実アカウント受入、実YMM4の起動は対象外。既存Git操作の安全条件と回復契約は維持した。

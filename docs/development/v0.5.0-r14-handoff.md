## 実装の境界

- **一覧とクラッシュ回復** `JsonProjectRepository`、`ProjectListPublications`、`ProjectListDrafts`。公開の操作 ID と結果ハッシュが確定した記録は閉じる。未公開を確認できた記録は BASE・LOCAL・REMOTE を比較し、利用者の選択後に最新データと照合して保存する。証拠不足時は別名退避。未知・破損データは「一覧原本を退避」でバイト列を保持したままコピーできる。[保存契約と切り戻し](../architecture/adr/project-list-publication-r14.md)
- **Identity とメタデータ** `ProjectFileEvidence`、`ProjectListIdentity`、`AssetRevisionSeries`。登録時または利用者の確認時に、Windows のボリューム・ファイル ID と SHA-256 を保存する。移動は確認済みのファイルを開いたまま一覧保存。旧データに根拠がない場合は、ファイルを検査して利用者に論理 ID の継続を確認する。分岐は親・先端を表示し、選択した先端だけを延長する。過去の版は維持する。
- **外部素材・再リンク** `AssetInventory`、`AssetRelinkRecovery`、`RelinkMainWindow`。論理保管先と相対パスを保存し、ルートは操作で明示する。URL はメタデータとして扱う。SaveAs → 版の照合・追加 → 一覧の切り替えの順。最後の段階で保存に失敗した場合は一覧の保存再試行、または元プロジェクトから回復記録を確認する。ファイルを再生成せず元ファイル・元参照を残す。
- **Git** `GitRepository` と `ProjectListViewModel`。Clone は入力先、Fetch は取得先、Push は接続先とブランチ・コミットを確認してから実行する。進行状況、取消、時間切れ、失敗分類、残った Clone 退避先を表示。approved モードの境界と Pull の無効化理由は [Git ADR](../architecture/adr/git-trust-model-r4.md)。
- **YMMPX** `YmmpxPackageReader`、`YmmpxLibBridge`。検証したファイル・ディレクトリのハンドルを使って上書きなしで公開。WPF は新規出力と明示登録に限定し、展開後にプロジェクトを自動で開かない。実パッケージの未同梱素材参照は引き継ぐ。

## ビルドと試験

Windows で隔離した参照 DLL のパスを `YMM4_PATH`、`YMM4DirPath` に設定する。 `TEMP` と `TMP` は独立領域に設定する。実ライブラリありの試験では `YMMPX_LIB_PATH` に隔離した `YmmpxLib.dll` を指定する。ビルドのコピー先も隔離した参照ディレクトリ内。

```powershell
dotnet build .\YMMProjectManager.sln -c Release "-p:YMM4_PATH=$env:YMM4_PATH" --nologo
dotnet build .\YMMProjectManager.sln -c Debug "-p:YMM4_PATH=$env:YMM4_PATH" --nologo
dotnet run --project .\YMMProjectManager.Tests -c Release --no-build
dotnet run --project .\YMMProjectManager.Tests -c Debug --no-build
$env:YMM_TEST_FILTER = 'RealYmmpxR5'
dotnet run --project .\YMMProjectManager.Tests -c Release --no-build
```

| Release 回帰、実 DLL あり | 0 | 59 / 0 グループ、個別 9 / 0 | 2 | 21.887 秒 |

skip は無効な Pull の2件と、実 DLL なし構成でのライブラリ検証1件。個別計測はグループの内訳であり、合算しない。

個別計測は一覧公開の8条件と再リンクの WPF 統合シナリオ。その他は既存のグループ内検証。別プロセス終了は `Environment.Exit` で後始末を通さず実施した。電源断やファイルシステム故障の試験は含まない。実 YMM4、共有 VM、本番 remote、利用者の Git グローバル設定は使用していない。

## レビューと再開

独立静的レビューで見つかった下書き作成順、ローカル順序の取りこぼし、再リンクの WPF スレッド違反、移動先の差し替え、承認前の Git 暗黙転送に対応した。機能上の残件のほか、公開レシートと閉じた記録の整理 UI、状態表示の集約、旧一覧の決定的な正規化が技術的負債として残る。過去の失敗試行の証拠が曖昧なまま残る場合、同じ下書きの後続試行が公開前に止まっても別名退避に限定する。

次は `ProjectListDrafts.Claim`、`JsonProjectRepository.SaveWithDraftAsync`、`ProjectListPublicationTests` から再開する。下書き取得直後からレシート記録までの中断を識別し、同じ下書きの古い未公開試行と後続試行を区別する。期限 2026-11-24、レビュー開始 2026-11-25。Pull・旧データの未完範囲を含む全要件の期限内完了は確約できない。

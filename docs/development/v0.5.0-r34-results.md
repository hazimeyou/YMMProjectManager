## ビルドと回帰の実行方法

隔離worktreeでYMM4参照に候補ルート内の `refs` を指定。下記コマンドの `$root` は上記のローカルルート。ReleaseとDebugを切り替え、終了0、警告0、エラー0を確認した。配備ターゲットは実行していない。

```powershell
dotnet build YMMProjectManager.sln -c Release --artifacts-path "$root/build" "-p:YMM4Path=$root/refs" -p:YMM4DeployPath= -p:ContinuousIntegrationBuild=true --nologo
dotnet build YMMProjectManager.sln -c Debug --artifacts-path "$root/build" "-p:YMM4Path=$root/refs" -p:YMM4DeployPath= -p:ContinuousIntegrationBuild=true --nologo
```

2026-11-25 JSTのReleaseは21:35:54〜21:35:58、単調計測4,668 ms。Debugは21:35:59〜21:36:04、5,143 ms。再実行では既存出力・証拠と別の新規ローカル領域を使う。

回帰は `build/bin/YMMProjectManager.Tests/<構成>/YMMProjectManager.Tests.exe` を直接起動。各Runの `TEMP` と `TMP` は別の隔離パス。公式ライブラリありは `YMMPX_LIB_PATH` に検証済みDLLを設定、なしは解除。旧版fixtureの格納先を `YMM_TEST_YMMPX_RELEASED_FIXTURES`、公式パッケージの保存先を `YMM_TEST_YMMPX_PLUGIN_ARCHIVE` に指定する。作成・展開と通信は合成fixtureとローカルの隔離HTTPSを使う。

## 合成GUI・安全性

- PMの合成WPFと描画元で、PFと所有者、サムネイルの取消後の破棄、比較の時刻と版、Timeline直接反映拒否、処理所有者の終了、旧PFと保存・回復記録の保全を検証した。検査対象は `PreviewComparisonTests`、`ThumbnailGalleryTests`、`LiveThumbnailSafetyTests`、`RelinkIntegrityTests`、`ProjectListPublicationTests`、`ProjectListWpfFixtureProcess.VerifyTimeoutAsync` など。
- 管理側の固定6工程について、R15の既存合成GUI・Recovery（23ケースおよびPowerShell 5スイート）を別途実行した。UIA階層差、対象不在と二重起動、時間切れ、証拠改変を含む。R16オフライン審査では現行定義の安全境界とR34候補の拒否理由を確認した。詳細と再試行の履歴は [管理側の独立照合](v0.5.0-r34-manager-evidence.md)。
- Worker BはRelease候補DLLを使った標準1.1・旧3形式の合成展開を4件確認した。標準1.1では素材4点の復元、PSDレイヤー参照の一致、未知フィールドと未解決の相対参照の保持を確認した。公式APIのみで作った入力は欠落通知の証明から除外した。
- [合成fixture](v0.5.0-r34-fixtures.md) の94ファイルを承認候補のmanifestと照合した。ハッシュ、期待する欠落、非上書き、版・素材名、環境変数による生成先逸脱を確認するツール試験はControllerと別担当で各11件成功。実YMM4の読込み状態は `NOT_VERIFIED`。
- 本番Scene（比較・新規サムネイル）、Timeline直接反映、実GitHubと実YMM4の受入は未実施。R34候補のVM試験は未承認。管理側の再ピンと新規承認が必要。

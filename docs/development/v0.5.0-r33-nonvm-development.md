## 分担と独立レビュー

- 除外設定・YMMPXは `2f23261` を `20db341` に統合した。予約方式の根拠・代替案と互換の範囲は [YMMPXの設計記録](v0.5.0-r33-ymmpx.md) を参照。
- 比較UI `c07c7c3` は `aac9afd`、サムネイルUI `703b588` は `3c8e02d` に統合した。各Workerは隔離参照で重点試験を実行した。Controllerの統合回帰は別に行った。
- 独立査読で指摘された任意フラグなしのローカル除外記録、比較設定の保存先境界、同じパスでPFが差し替わる表示直前の競合を修正した。描画結果のない側の時刻、未計測フォルダー、キャッシュ探索の取消も改善した。

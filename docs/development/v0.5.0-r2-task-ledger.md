## R2 調査・実装メモ

- 既存 UI 差分を一時 patch として隔離保存し SHA-256 `791688A449B6F1620FFBC72AB83AF9616883E7984247E2E6DDCA2745680A6354` を記録。元 worktree は操作せず、未追跡はなく5件の tracked 変更。変更は generation UI のデフォルト無効化と設定永続化で、Git の操作画面ではない。旧系統の UI をそのまま port すると、新設定の通知更新と保存失敗時の2回書込みの整合性が未検証なため、今回の Git UI に混ぜていない。
- Git の remote API: `origin` が単一、ローカル絶対パスまたは資格情報・query を含まない HTTPS のみ。pull は同名 branch の `--ff-only`、push は現在 branch の明示 refspec、force なし。helper / hook は Git 自身の挙動として残る。実行出力には任意の秘密が含まれうるため、remote 結果の raw stdout/stderr は公開しない。エラー分類は英語メッセージに基づく限定的なもの。SSH、複数 remote、credential 対話、競合解消、timeout・hook・helper 境界の追加試験は未完了。リモート URL 確認から Git 実行までの設定競合も未解決。
- 分岐時の push/pull 拒否は local bare remote により再現し、元の HEAD 不変を確認。実ネットワーク・認証は未使用。clone は同一親に OS の排他的ディレクトリ作成で一時領域を確保し、完了後に上書き不可の Directory.Move を行う。移動前の宛先競合は決定的試験で元データ維持と回復先を確認。異常時は一時領域を保持する。clone UI は未実装。

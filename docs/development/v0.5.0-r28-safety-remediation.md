# R28 データ保全と実行環境の修正

2026-11-25 JST。指示IDは YMMPM-R28-SAFETY-REMEDIATION-20261125。基準はユーザー調整用ブランチと origin で一致した 4e2629a474129cb1f244b0536a36011386e4b192。R27の静的監査から、世代操作、ビルド、試験選択、サムネイル、診断と設定の問題を扱う。

## 保存と復元の設計

- 世代削除の退避先は無上書き移動で予約する。事前検査後に同名先が現れても置き換えず、通常の移動に成功してからmanifestを更新する。
- 元PFの復元では承認対象をストレージの保有ハンドルに結び付け、検証した世代データを専用一時ファイルとして確定する。元PFの退避と新ファイルの公開はいずれも無上書きとし、途中で競合した場合は元PFを同一ハンドルで回復するか、退避先に保持する。別名復元も従来の操作から利用できる。
- 設定は読み込んだ物理ファイルIDと内容のSHA-256を照合する。候補の書込み完了後に確定し、同じ操作の中でメモリも更新する。競合時の回復先は既存ファイルを置き換えず、復元できない場合は一意な名前の旧版を保持する。JSONの SearchFolders は従来と同じで、BOM付きの既存入力も読める。候補への書込み前に旧ファイルの権限とメタデータが維持できることを検証する。設定が破損または読取り不能なときはそれまでの確認済み値を保持し、再読込に成功するまで保存を拒否する。
- 復元と設定保存は所有ハンドルに対して後始末する。旧版の退避と新ファイルの公開は2段階なので、強制終了後に元の名前が空く場合がある。設定の旧版は同じ settings ディレクトリの YMMProjectManagerSettings.json.previous-<操作固有名>、元PFの通常の退避先は世代ストレージの projects/<対象ID>/restore-backups にある。別ボリュームの場合は元PF側に確保した退避先も確認する。回復時は現用ファイルと退避候補の両方を保全し、利用者が対象を選んで別名のコピーを検証する。合成の別プロセスを退避直後に Environment.Exit で終了する試験では、元PF・設定の旧版を再起動後に読み取れた。設定の現用名が空の場合は再読込と新規保存を拒否した。OSによる強制終了と電源断、自動回復は未検証。

## 診断、ビルド、試験

- Loggerは最初の書込み時にディレクトリを用意する。作成失敗はベストエフォートの診断内で処理し、ツールの起動を継続する。例外フックはロードコンテキストに紐付け、WPF Dispatcherの終了または明示的なアンロードで関連する購読を解除する。グローバル例外では型・HResult・ソースパスなしのスタックを記録する。製品全体の任意ログ文言を一括変更する施策はこの差分に含まない。
- ビルドの参照先は YMM4_PATH / YMM4DirPath、明示配備先は YMM4DeployPath。配備には DeployToYMM4 ターゲットが必要。[開発用配備手順](../../README.md)
- タグ用配布workflowはYMM4 Lite版の参照アーカイブを固定し、Releaseの合成試験を通過した成果物のコミット、参照DLL、パッケージSHA-256を別のJSONアセットへ記録する。従来と同じ .ymme 形式を使う。
- 試験は一つの登録表から既定・個別選択を実行する。対象が0件、未知の名前、同一グループの重複指定を失敗として報告する。グループ内の条件付きスキップ、グループ失敗、選択後の未実行を集計に含める。子プロセスモードとWPF STAは既存のまま利用する。HTTPS試験の準備ファイルは完成後に名前を確定する。

## ライブサムネイルの受入境界

YMM4 4.57.0.1 Liteの参照DLLをPEメタデータとILで調べた。メインのモデル、Timeline、Scenes、プレビューとプレイヤーの対応、および保存済みフラグを確認できる。保存済みフラグは、ホストが読み込んだファイルの物理IDや内容の版を示さない。開始前に同じパスへ別のPFが現れた場合、現在のファイルIDとタイムラインの保存済み状態を調べても、読み込み時の版を証明できない。

この版からのライブ取得は、読み込み時のファイル版を照合できるまでシークと新規キャッシュ公開の前で停止する。既存の取得コマンドと旧キャッシュの表示を維持する。取得元の証拠を渡せる合成経路では、開始前・フレームごと・公開前の再照合、別PFへの切替、取消、シーク失敗後の復帰、同一時刻の別ファイルを区別するキャッシュキー、公開マーカーまでのファイル保護を確認する。旧形式のキャッシュは移行前のキーで参照し、新規世代は物理IDを含む別の名前空間に公開する。

Eを再開するには、YMM4から対象モデルの読込・保存とファイル版が対応する証拠を取得するか、選択PFを保持してロード完了を確認できる経路を設計する。実ホストのシークは外部から取り消せないため、既に始まった呼び出しの完了を待ってから取消として扱う。実機で、手動移動・途中切替・停止・フレーム復帰を確認するまでは、合成試験の成功と実機受入を区別する。

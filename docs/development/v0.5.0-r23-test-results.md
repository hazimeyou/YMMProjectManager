# v0.5.0 R23 試験結果

実行はすべて本番YMM4を起動しない隔離fixture。Windows ローカルNTFS、隔離した既存YMM4参照DLL、.NET SDK 10.0.404。実YmmpxLib 1.1.0のSHA-256は `107A522AAC5C0AAFD32494C0C93AC9404694FBA6A4BAD7902B78D0F000C2E552`。実YMM4、実GitHub、共有VMは未使用。旧版の検証は公開タグのCLIを隔離ビルドして合成入力から生成したfixtureに限定した。

```powershell
dotnet build .\YMMProjectManager.sln -c Release '-p:Version=0.5.0' --nologo
dotnet build .\YMMProjectManager.sln -c Debug '-p:Version=0.5.0' --nologo
dotnet run --project .\YMMProjectManager.Tests -c Release --no-build
dotnet run --project .\YMMProjectManager.Tests -c Debug --no-build
```

`YMM4_PATH` と `YMM4DirPath` の両方にビルド・実行構成ごとの隔離DLLコピーを設定。 `TEMP` と `TMP` に実行ごとの新規隔離フォルダーを設定。実ライブラリありの試験だけ `YMMPX_LIB_PATH` を隔離DLLへ設定する。全回帰では `YMM_TEST_FILTER` を解除。重点試験は `YmmpxTransferTests`、`GitPublicationTests` と `GitHttpsAcceptanceTests`。HTTPSの認証関連試験は、隔離した別のループバック応答を含む製品Git経路を実行する。

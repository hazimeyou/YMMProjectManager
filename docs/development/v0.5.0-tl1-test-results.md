TL-1 の実装と回帰は合成データで検証した。別実装の数値照合も完了した。実装者と別のレビュアーによる差分レビュー、および YMM4 実機受入は未実施。

## 対象と隔離

指示 ID は YMMPM-TL1-COMPARISON。基点は R17 統合ブランチの 6d11d6c0426e9f5cf0b7ae8661bb42eeb2d79b09。origin は hazimeyou/YMMProjectManager。既存の checkout は割り当て直さず、TL-1 専用の worktree を作成した。着手後に R18 の統合・Git・一覧・素材の4作業ツリーが作成された。R18 の Git 査定・オフライン UI・一覧公開テストの差分と、TL-1 の比較コードおよび試験に重複はなかった。共有テストランナーへの変更は、全回帰と絞り込みへの比較試験登録の4行。

.NET SDK 10.0.404 を使用。以前の隔離参照の3 DLL と YmmpxLib.dll を新しい一時ディレクトリにコピーした。ビルド後の CopyToYMM4 ターゲットの書き込みも、実行ファイルを含まない隔離参照ディレクトリ内。テストは構成ごとの TEMP / TMP と、テストランナーが作るローカル Git fixture を使用した。

## 別実装による照合と差分点検

検証ディレクトリの oracle で、実装のソースを複製せずビルドした Release アセンブリを参照して実行した。時刻側の参照実装は Python の Fraction で時刻とフレーム開始を表し、二分探索で該当フレームを選択した。画像側は絶対差のヒストグラムと画素ごとのバイト列比較から期待値を求めた。固定 seed で、時刻 969 件と画像 150 件が一致した。検証ツールのビルドは終了コード0、警告0、エラー0。

~~~powershell
Set-Location "$root\oracle"
dotnet build .\Oracle.csproj -c Release --nologo
python .\oracle.py .\bin\Release\net10.0-windows\YMMProjectManager.Tests.dll
~~~

実装者の差分点検では以下を確認した。

- インデックス計算では有理数の積を Int128 に収め、範囲確認後に int に変換する。半開区間、端数 tick、空の Scene、TimeSpan 最大値を確認した。
- 画素数とバッファ長の検査、チャンネル差の上限、合計の軸を確認した。4K の全変更で差の合計が int を超えることを回帰で検証した。検証順序を見直し、未対応形式を BGRA32 の長さで判定する前に拒否するよう修正した。
- 入力の所有権を呼び出し側に置き、共有した可変状態・画像サイズに比例する追加領域・入力書き込みを排除した。4K の追加割り当ての上限、並行比較、取り消し済みトークンと再試行をテストした。処理中の取り消し間隔はコードの点検対象。
- 比較処理に YMM4 SDK・WPF・I/O・既存製品経路への接続がないことを差分で確認した。対象やフレームの不一致を画素の走査前に拒否する。未検証のホスト由来メタデータの真正性は将来の接続側が確認する。

TL-1 の残件は別レビュアーによる差分確認。実ホスト接続・受入の範囲は[ホスト接続条件](v0.5.0-tl1-host-contract.md)を参照。v0.5.0 のリリース判定は R17 と同じ。

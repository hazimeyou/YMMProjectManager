## 精査した動作

- 時刻の分子は有効入力内で 2^94 未満、分母は正で 2^55 未満。半開区間、100 ns に載らない端数境界、空・負値・片側だけが範囲内の場合を確認した。インデックスはフレーム数未満であることを確かめてから int に変換する。
- 要求と受領画像でスナップショット記述とインデックスを完全照合する。ホスト側の出所と失効を証明する部分は TL-2 の契約。
- 比較時の長さは packed straight BGRA32 ちょうど。別形式・非対応形式は分類して拒否する。alpha と透明画素の RGB の扱いは文書とテストに一致する。最大バッファは 2,147,483,644 バイト、最大絶対差合計は 547,608,329,220 で long に収まる。
- 走査は入力を変更せず、コアの追加割り当ては一定。並行利用時にバッファを変更しないことが呼び出し側の前提。取消は例外で返り、途中のメトリクスを公開しない。分類と側の情報は検査順に従う。
- SDK、WPF、I/O や既存製品経路への結合がない。既存機能の差分はテストランナーの登録のみ。TL-1 コード本体・時刻ポリシーは保持した。変更後の試験結果は [TL-2A 検証結果](v0.5.0-tl2a-test-results.md) を参照。

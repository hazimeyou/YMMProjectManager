# v0.5 public review snapshot

This branch contains one review snapshot on public master, not the local development commit history. Product source and tests are identical to the R11 integrated tree. This is a draft review, not a release candidate.

## Publication scope

The local R1-H and R1-H2 architecture audit directories are intentionally excluded because they contain private workstation inventory and environment-specific observations. Original local branches and reports are preserved separately. No product code or tests are omitted.

Real YMM4 acceptance remains incomplete. Isolation must be proven before launching YMM4; separate directories alone are not an isolation boundary. Do not copy plugin outputs into a production installation. See [R11 handoff](v0.5.0-r11-handoff.md) and [R7 validation](v0.5.0-r7-validation.md) for preparation and outstanding acceptance work.

No build or test was rerun while preparing this snapshot. Earlier R11 results are historical reports, not fresh validation. Git Pull and YMMPX bridge extraction remain disabled. Default version remains 0.4.0 pending a future release decision.

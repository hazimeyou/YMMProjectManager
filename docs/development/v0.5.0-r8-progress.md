## 実装済みの範囲

- 新規登録した project list の entry に GUID を割り当て、一覧 JSON に保存・再読込する。YMM project 自体は変更しない。旧一覧の未設定 ID は null のままとし、空・重複 ID と ID 付きパス欠落を拒否する。保存失敗時は既存一覧を上書きしない。
- ID がある project から作る asset manifest は同じ ID を持つ。親 revision の ID が異なる更新を拒否し、ID 一致時は名前が変わっていても明示確認の下で revision を作れる。既存 revision は create-only のまま。旧 project / 旧配列の関連付けは未確認と表示する。
- ファイル側 relink の確認画面で、選択した metadata の project ID が一致する場合、期待 SHA-256 と候補 SHA-256 の一致・不一致・期待値なしを表示する。確認画面の値を保存直前に再計算し、変化を検出したら中止する。元 project は既存の SaveAs 処理により保護する。新しい metadata revision は作成せず、その旨を表示する。timeline mutation は従来どおり無効。

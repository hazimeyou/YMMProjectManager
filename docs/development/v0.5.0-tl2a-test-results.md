.NET SDK 10.0.404。TL-1 の隔離参照から3つの YMM4 DLL と YmmpxLib.dll を専用ディレクトリへコピーした。プロジェクトの CopyToYMM4 は実行ファイルのない隔離参照ディレクトリ内に開発 DLL を出力する。構成別 TEMP/TMP と合成プロジェクト、ローカル Git fixture を使用。本番 YMM4、既存プロジェクト、共有 VM、R18 および YMMPrint の作業ツリーへの書き込みは行っていない。

## コマンド

$root は隔離ログ・参照ディレクトリ C:\Users\hazimeyou\AppData\Local\Temp\tl2a-0d4f4dc5。基点の再検証コマンドは元の TL-1 worktree で実行した。TL-2A コマンドは専用 worktree で実行した。

~~~powershell

$env:YMMPX_LIB_PATH = "$root\ymmpx\YmmpxLib.dll"

# TL-1 base at 793ebf354e755ca7cd862b8d9301885a2d0a717b

$env:TMP = $env:TEMP

dotnet build .\YMMProjectManager.sln -c Debug "-p:YMM4_PATH=$env:YMM4_PATH" --nologo

$env:TEMP = "$root\focused"

$env:YMM_TEST_FILTER = ''
$env:TEMP = "$root\release"

$env:TEMP = "$root\debug"
~~~

TL-1R の独立レビューは全差分と最終 TL-1 Release DLL を対象に行い、時刻969件・画像150件の別実装照合も再度成功した。TL-2A の差分レビューでは P0〜P2 の指摘なし。P3 について、コピー先に計画が発行したスロットを要求し、未発行の記述を直接渡す構造を除いた。並行試験を2ワーカーのランデブーに変更し、要求の同時進行を確かめた。修正後に両構成で再ビルド・全回帰を実施した。

この検証のビルドは PM を隔離 SDK 参照でコンパイルした記録。新規コンポーネントは SDK に依存しない。描画、ホスト状態保全、資源解放、ホストの排他は実機未実施。YMMPrint の SDK マトリクスは別作業の証拠として [Scene 契約](v0.5.0-tl2a-scene-contract.md) に記載した。
